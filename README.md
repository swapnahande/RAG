# RAG
A simple RAG chatbot built with Streamlit, LangChain, Hugging Face, and FAISS for context-based question answering with source-aware responses.

# Simple RAG Chatbot with Streamlit

This project is a simple **Retrieval-Augmented Generation (RAG)** chatbot built using **Streamlit, LangChain, Hugging Face, and FAISS**.

The chatbot:
- accepts user questions
- retrieves relevant information from stored documents
- generates responses using an LLM
- cites the source document if the answer comes from the document
- otherwise mentions **General Knowledge**
